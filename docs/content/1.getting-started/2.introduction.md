Welcome to **Authyra**, a modular and type-safe authentication framework built for the Dart and Flutter ecosystem.

## What is Authyra?

Authyra is designed to solve the common pain points of authentication in modern applications: tight coupling with UI frameworks, hard-to-test logic, and rigid session management.

Instead of being a "black box" plugin, Authyra provides a **Core Engine** written in pure Dart, allowing you to manage your authentication logic independently of your Flutter UI. Whether you are using simple Email/Password login or complex OAuth2 flows, Authyra ensures a consistent and predictable developer experience.

## Key Features

Our architecture is built on three main pillars:

- **Modularity**: Every part of the system (Storage, Providers, Logic) is swappable.
- **Testability**: Designed with TDD in mind. Mocking providers or storage is straightforward.
- **Security**: Built-in protection against common pitfalls, including secure token handling and PKCE support for OAuth.
