## 1. Install

```yaml [pubspec.yaml]
dependencies:
  authyra: ^0.1.0
```

```bash
dart pub get
```

---

## 2. Create an `AuthyraClient`

`AuthyraClient` is the stateless core — it holds your providers and storage configuration. No global state, fully testable.

```dart [main.dart]
import 'package:authyra/authyra.dart';

final client = AuthyraClient(
  providers: [
    // Simple user-only flow — your backend returns just the user profile.
    CredentialsProvider(
      id: 'email',
      authorize: (creds) async {
        final res = await myApi.post('/auth/login', body: creds);
        if (res.statusCode != 200) return null; // wrong credentials
        return AuthUser(
          id:    res.data['id'],
          email: res.data['email'],
          name:  res.data['name'],
        );
      },
    ),
  ],
  storage: InMemoryAuthStorage(), // swap with SecureAuthStorage in production
);
```

::callout{icon="i-lucide-lightbulb"}
If your backend returns JWT tokens in the sign-in response, use `CredentialsProvider.withTokens` instead — it stores `accessToken`, `refreshToken`, and `expiresAt` in the session automatically.
::

---

## 3. Initialize the singleton

```dart [main.dart]
void main() async {
  // Restores any session persisted from the previous run.
  await Authyra.initialize(client: client);

  // At this point Authyra.instance is ready everywhere.
  runMyApp();
}
```

`Authyra.initialize` is idempotent — calling it a second time returns the existing instance unchanged.

---

## 4. Sign in

```dart
final user = await Authyra.instance.signIn('email', params: {
  'email':    'alice@example.com',
  'password': 's3cr3t',
});

print('Hello, ${user.name}!');
```

`signIn` throws on infrastructure errors (`AuthenticationFailedException`, `ProviderNotFoundException`, etc.) and returns `AuthUser` on success. If the provider callback returns `null`, `signIn` throws `AuthenticationFailedException` — never returns `null`.

---

## 5. React to auth state

```dart
// Broadcast stream — identical consecutive states are deduplicated.
Authyra.instance.authStateChanges.listen((AuthState state) {
  switch (state.type) {
    case AuthStateType.authenticated:
      print('Signed in as ${state.user!.email}');
    case AuthStateType.unauthenticated:
      print('Signed out');
    case AuthStateType.error:
      print('Error: ${state.error}');
  }
});
```

Or read state synchronously (safe in build methods — no awaiting needed):

```dart
if (Authyra.instance.isAuthenticated) {
  final user = Authyra.instance.currentUser!;
  print('Welcome back, ${user.name}');
}
```

---

## 6. Sign out

```dart
await Authyra.instance.signOut();
// authStateChanges emits AuthState.unauthenticated()
```

## Full example — pure Dart CLI

```dart [bin/main.dart]
import 'package:authyra/authyra.dart';

Future<void> main() async {
  // 1. Build client
  final client = AuthyraClient(
    providers: [
      CredentialsProvider(
        id: 'email',
        authorize: (creds) async {
          // Simulate an API call
          if (creds?['password'] == 'secret') {
            return AuthUser(id: '1', email: creds!['email'] as String);
          }
          return null; // wrong password
        },
      ),
    ],
    storage: InMemoryAuthStorage(),
  );

  // 2. Initialize (restores persisted session if any)
  await Authyra.initialize(client: client);

  // 3. Listen to state changes
  Authyra.instance.authStateChanges.listen((state) {
    print('[auth] ${state.type.name}');
  });

  // 4. Sign in
  try {
    final user = await Authyra.instance.signIn('email', params: {
      'email':    'alice@example.com',
      'password': 'secret',
    });
    print('Signed in: ${user.email}');
  } on AuthenticationFailedException catch (e) {
    print('Wrong credentials: $e');
  }

  // 5. Access session data
  final session = await Authyra.instance.getSession();
  print('Token: ${session?.accessToken}');

  // 6. Sign out
  await Authyra.instance.signOut();
  print('Signed out. Authenticated: ${Authyra.instance.isAuthenticated}');

  // 7. Tear down
  await Authyra.instance.dispose();
}
```
