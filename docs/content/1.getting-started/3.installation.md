## Requirements

- **For Dart projects**: Dart SDK ≥ 3.0.0
- **For Flutter projects**: Flutter SDK ≥ 3.0.0

## Installation

### Flutter Apps

Add `flutter_authyra` to your `pubspec.yaml`:

```yaml
dependencies:
  flutter_authyra: ^0.1.0
```

This automatically includes the core `authyra` package.

Run:

```bash
flutter pub get
```

### Dart Backend / CLI

Add `authyra` to your `pubspec.yaml`:

```yaml
dependencies:
  authyra: ^0.1.0
```

Run:

```bash
dart pub get
```
