## Requirements

- Dart SDK **≥ 3.5.0**

Authyra's core package has no Flutter dependency and works on every Dart platform.

## Install

Add `authyra` to your `pubspec.yaml`:

```yaml
dependencies:
  authyra: ^0.1.0
```

Then fetch dependencies:

```bash
dart pub get
# or, inside a Flutter project:
flutter pub get
```

## Verify

```dart
import 'package:authyra/authyra.dart';

void main() {
  print(AuthyraInstance.isInitialized); // false — not yet initialized
}
```

## What's included

The `authyra` package ships everything you need for the core authentication layer:

| What                      | Description                                              |
| ------------------------- | -------------------------------------------------------- |
| `AuthyraClient`           | Stateless orchestrator — providers + storage + sessions  |
| `AuthyraInstance`         | Singleton wrapper with reactive streams and sync state   |
| `AuthProvider` interface  | Extend to build any custom auth strategy                 |
| `CredentialsProvider`     | Email / password out of the box                          |
| `OAuth2Provider`          | Authorization Code + PKCE for any OAuth2 provider        |
| `GoogleProvider`          | Prebuilt Google Sign-In                                  |
| `GitHubOAuth2Provider`    | Prebuilt GitHub OAuth                                    |
| `ProxyOAuthProvider`      | Backend-delegated OAuth (client secret stays on server)  |
| `AuthStorage` interface   | Plug in any persistence layer                            |
| `InMemoryAuthStorage`     | In-memory store for tests and development                |
| `AccountManager`          | Multi-account switching and sign-out                     |
| `SessionManager`          | Async-safe session registry with optional auto-refresh   |
