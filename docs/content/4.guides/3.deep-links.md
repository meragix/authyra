Any `OAuth2Provider` (or a prebuilt subclass: `GoogleProvider`, `GitHubOAuth2Provider`, `AppleProvider`) opens an external browser for the authorization step, then needs the resulting redirect routed back into your app. `OAuth2CallbackHandler` is the static registry that does that routing.

`ProxyOAuthProvider` is the exception: it manages its own deep-link routing via `handleDeepLink`, don't register it with `OAuth2CallbackHandler`. See [ProxyOAuthProvider →](/providers/proxy-oauth).

---

## 1. Register each provider

Register before `Authyra.initialize()`, keyed by the URI scheme the provider redirects back to (without `://`):

```dart
OAuth2CallbackHandler.registerProvider('myapp', discordProvider);
OAuth2CallbackHandler.registerProvider(
  'com.googleusercontent.apps.YOUR_CLIENT_ID',
  googleProvider,
);
```

::callout{icon="i-lucide-triangle-alert"}
Routing is by scheme only. Registering a second provider under the same scheme **silently replaces** the first, last one wins. Give each provider a distinct scheme if you support more than one OAuth2 provider at once.
::

## 2. Forward incoming links

With `package:app_links` (what the rest of these docs use):

```dart
import 'package:app_links/app_links.dart';

AppLinks().uriLinkStream.listen(OAuth2CallbackHandler.handleCallback);
```

Or forward manually from wherever your app already sees the URI (a custom `onGenerateRoute`, a GoRouter redirect):

```dart
final incoming = Uri.parse(link);
OAuth2CallbackHandler.handleCallback(incoming);
```

`handleCallback` looks up `uri.scheme`, delegates to the matching provider, and logs a warning (does not throw) if nothing is registered for that scheme.

## 3. Initialize Authyra

```dart [lib/main.dart]
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  OAuth2CallbackHandler.registerProvider('myapp', discordProvider);
  AppLinks().uriLinkStream.listen(OAuth2CallbackHandler.handleCallback);

  await Authyra.initialize(
    client: AuthyraClient(
      providers: [discordProvider],
      storage: SecureAuthStorage(),
    ),
  );

  runApp(const MyApp());
}
```

## Platform setup

Register the custom URI scheme with each platform, independent of Authyra:

**Android**, `android/app/src/main/AndroidManifest.xml`:

```xml
<intent-filter>
  <action android:name="android.intent.action.VIEW" />
  <category android:name="android.intent.category.DEFAULT" />
  <category android:name="android.intent.category.BROWSABLE" />
  <data android:scheme="myapp" android:host="auth" android:pathPrefix="/callback" />
</intent-filter>
```

**iOS**, `ios/Runner/Info.plist`:

```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>myapp</string>
    </array>
  </dict>
</array>
```

## Cleanup

```dart
// One provider
OAuth2CallbackHandler.unregisterProvider('myapp');

// Everything, useful in test teardown
tearDown(OAuth2CallbackHandler.clearAll);
```
