## Overview

`Authyra.instance` is the singleton entry point for authentication in your app.

```dart
import 'package:authyra/authyra.dart';

// Access the singleton
final instance = Authyra.instance;
```

## Methods

### configure()

Configure Authyra with an `AuthyraClient`.

**Must be called before `initialize()`.**

```dart
void configure(AuthyraClient client)
```

**Example**:

```dart
Authyra.instance.configure(
  AuthyraClient(
    providers: [EmailAuthProvider()],
    storage: SecureAuthStorage(),
  ),
);
```

---

### initialize()

Initialize Authyra and restore session from storage.

**Must be called once at app startup, after `configure()`.**

```dart
Future<void> initialize()
```

**Example**:

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  Authyra.instance.configure(...);
  await Authyra.instance.initialize();
  
  runApp(MyApp());
}
```

**Returns**: `Future<void>`  
**Throws**: `StateError` if not configured

---

### signIn()

Authenticate a user with credentials.

```dart
Future<AuthAccount?> signIn({
  required String provider,
  required Map<String, dynamic> credentials,
})
```

**Parameters**:

- `provider` (String): Provider ID (e.g., 'email', 'google')
- `credentials` (Map): Provider-specific credentials

**Example**:

```dart
final account = await Authyra.instance.signIn(
  provider: 'email',
  credentials: {
    'email': 'user@example.com',
    'password': 'secret123',
  },
);

print('Logged in as: ${account?.displayName}');
```

**Returns**: `AuthAccount?` (null if failed)  
**Throws**: `AuthException`, `InvalidCredentialsException`

---

### signOut()

Sign out the current user.

```dart
Future<void> signOut()
```

**Example**:

```dart
await Authyra.instance.signOut();
// User is now logged out
```

**Returns**: `Future<void>`

---

### refresh()

Refresh the current user's token.

```dart
Future<bool> refresh()
```

**Example**:

```dart
final success = await Authyra.instance.refresh();
if (success) {
  print('Token refreshed');
} else {
  print('Refresh failed, user logged out');
}
```

**Returns**: `bool` (true if success, false if failed and user logged out)

---

## Properties

### currentAccount

Get the current authenticated account (synchronous).

```dart
AuthAccount? get currentAccount
```

**Example**:

```dart
final account = Authyra.instance.currentAccount;
if (account != null) {
  print('Logged in as: ${account.email}');
}
```

**Returns**: `AuthAccount?` (null if not authenticated)

---

### allAccounts

Get all stored accounts (synchronous).

```dart
List<AuthAccount> get allAccounts
```

**Example**:

```dart
final accounts = Authyra.instance.allAccounts;
for (final account in accounts) {
  print('Account: ${account.email}');
}
```

**Returns**: `List<AuthAccount>` (unmodifiable list)

---

### isAuthenticated

Check if user is authenticated (synchronous).

```dart
bool get isAuthenticated
```

**Example**:

```dart
if (Authyra.instance.isAuthenticated) {
  print('User is logged in');
}
```

**Returns**: `bool`

---

### onAccountChanged

Stream of authentication state changes.

```dart
Stream<AuthAccount?> get onAccountChanged
```

**Example**:

```dart
Authyra.instance.onAccountChanged.listen((account) {
  if (account == null) {
    print('User logged out');
  } else {
    print('User logged in: ${account.email}');
  }
});
```

**Returns**: `Stream<AuthAccount?>` (null = logged out)

---

### toNotifier()

Get a `Listenable` adapter for routing frameworks.

```dart
Listenable toNotifier()
```

**Example** (with GoRouter):

```dart
final router = GoRouter(
  refreshListenable: Authyra.instance.toNotifier(),
  redirect: (context, state) {
    final isAuth = Authyra.instance.isAuthenticated;
    // ...
  },
);
```

**Returns**: `Listenable`

## Complete Example

```dart
import 'package:flutter/material.dart';
import 'package:flutter_authyra/flutter_authyra.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 1. Configure
  Authyra.instance.configure(
    AuthyraClient(
      providers: [EmailAuthProvider()],
      storage: SecureAuthStorage(),
    ),
  );
  
  // 2. Initialize
  await Authyra.instance.initialize();
  
  // 3. Listen to changes (optional)
  Authyra.instance.onAccountChanged.listen((account) {
    print('Auth changed: ${account?.email}');
  });
  
  runApp(const MyApp());
}

class LoginButton extends StatelessWidget {
  const LoginButton({super.key});
  
  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () async {
        // 4. Sign in
        await Authyra.instance.signIn(
          provider: 'email',
          credentials: {'email': 'user@app.com', 'password': '***'},
        );
      },
      child: const Text('Login'),
    );
  }
}

class LogoutButton extends StatelessWidget {
  const LogoutButton({super.key});
  
  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () async {
        // 5. Sign out
        await Authyra.instance.signOut();
      },
      child: const Text('Logout'),
    );
  }
}

class UserInfo extends StatelessWidget {
  const UserInfo({super.key});
  
  @override
  Widget build(BuildContext context) {
    // 6. Access current account
    final account = Authyra.instance.currentAccount;
    
    if (account == null) {
      return const Text('Not logged in');
    }
    
    return Text('Logged in as: ${account.email}');
  }
}
```
